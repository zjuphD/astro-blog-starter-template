# 官网能力说明调整

原首页强调引用与复算，但能力区只有四句概述，访客不容易知道可以提交哪些材料、获得哪些文件。首次使用说明还保留了旧的手动创建密钥流程。

本次中英文首页同步调整：

- 首屏明确论文、数据表、实验记录等输入，以及图表、报告、组会 PPT 等成果。
- 八项常用任务各自列出输入、输出与提问示例：文献检索、对照精读、生信与实验数据分析、科研绘图、论文与报告、PPT 与讲稿、文献雷达、课题资料导入和记忆。
- GeneCode 保留独立的序列图谱展示，补充序列、载体输入与克隆方案、引物、序列文件输出。
- 用 qPCR 数据到组会汇报的示例说明结果表、脚本、图、报告、PPT 的交付关系；示例标注清楚，不作为实际科研结果或固定数量承诺。
- 补充课题资料导入、记忆确认、任务看板手动状态与执行按钮的区别，以及文献雷达依赖客户端运行的说明。
- 上手步骤改为注册、安装并登录、选择课题与交办任务，与当前 Beta 登录实现一致。
- 引用检验示意改用用户可读的报告标题，结果核对说明改为来源、方法、脚本和证据边界，避免绝对准确性承诺。

保持原字体、色彩、玻璃表面、背景网格与图案；没有改动视频、定价、账户交互和 Aiseeki 路由。基于当前 GitHub main 建立独立工作副本，没有覆盖历史本地改动。

能力文案核对依据：BioSeeki 当前科研技能目录、知识库课题导入实现、文献雷达文档、账号首启登录实现，以及任务看板工作流记录。格式支持指通用资料或常见对话导出，并非所有第三方 Agent 私有格式。

验证：`npm run check` 通过（Astro 构建、TypeScript 与 Worker 部署预检查）。真实浏览器检查中文和英文页面、默认桌面视口及 390px 手机视口；八项说明完整，中文锚点存在，手机列表单列且无横向溢出，原背景与玻璃质感仍可见。
